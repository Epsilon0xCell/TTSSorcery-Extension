What this is

TTSSorcery is a SillyTavern extension in three files, index.js, style.css, and manifest.json version 1.0. It gives one streamed chat reply many voices at once. It is not part of, and does not work with, the text to speech built into SillyTavern, and it works with chat completions only, not text completion.

Card holds: the scope of the extension.

The marker at the centre

An injected prompt asks the model to write speech markers into its reply, in the form §c:Character|happy.mp3|e1:0.8§, where the marker names who is speaking, which voice file or emotional variant to use, and an emotion value. The extension reads those markers as the reply streams, sends each segment to the Zyphra text to speech endpoint over HTTPS, and plays the returned audio in order, so a line is heard while the rest of the reply is still arriving. Preloading fetches later segments early so playback does not stall mid message.

Card holds: the marker, the stream, and the endpoint.

Setup, branch by branch

  1. Get a Zyphra API key, the free tier giving 100 minutes a month.
  2. Put the key in the extension settings.
  3. Upload at least one voice sample for the Narrator.
  4. Add character voices as needed.
  5. Enable the extension.

Any audio sample can be uploaded to clone a voice. Samples of 10 to 30 seconds work best, noisy samples call for speaker denoising, and emotional variants such as happy, sad, or angry can be added without limit under names the model can match to context.

Card holds: key, Narrator sample, and variants.

The dials and the preset shelf

Six languages are listed: English, Japanese, Chinese, French, German, and Korean. Emotion values run across eight named feelings: happiness, sadness, disgust, fear, surprise, anger, other, and neutral. Settings presets save the model, language, speaking rate, voice quality score, and denoising choice under a name, can be imported and exported as JSON, and change when a setting changes.

Tip, in plain type: pick the hybrid model over the transformer for better voice quality.

Use and honest limits

Auto generation speaks new messages only while streaming is on. Manual generation starts from the wand icon in the menu, or the three dots on a message and then the wand. Playback can be toggled inside SillyTavern.

The warnings, unsoftened: the author calls the extension buggy, says about 80 percent of its success rests on having a capable model, and warns that the marker finding regular expression breaks when a model places markers badly. Testing is named narrowly: Claude 3.7, Claude 3.5, Claude Opus, Claude Haiku, and Gemini Pro. The extension cannot load outside SillyTavern at all.

Its 15 Node tests, run with node --test tests/index.test.mjs, load index.js against stubbed host modules and cover marker parsing, segment building, queue resets, the preload request body, preset seeding, and emotion mapping. Playback inside a real SillyTavern install is not covered by them.
