TTSSorcery-Extension

A SillyTavern extension that generates text to speech with multiple speakers and emotions inside a single message. One page, many voices: an injected prompt marks up the reply as it is written, one band per character, and the extension voices each band through Zyphra's API the moment it streams in rather than reading the message afterwards.

How it works

  1. A prompt is injected to make the AI add special text to speech markers to the text: §c:Character|happy.mp3|e1:0.8§
  2. These markers tell the extension who is speaking, which voice file to use, and in what emotion.
  3. The extension processes these markers and sends them to Zyphra's API, over HTTPS at api.zyphra.com/v1/audio/text-to-speech.
  4. Zyphra returns audio files that are played in order.

It uses the method and some code and prompts from p-e-w/sorcery, attributed in the repo. It is NOT integrated or compatible with SillyTavern's built in text to speech, and only works with chat completions for now.

Set it up

  1. Get a Zyphra API key (the free tier gives 100 minutes a month).
  2. Add your API key in the extension settings.
  3. Upload at least one voice sample for the Narrator.
  4. Add character voices as needed.
  5. Enable the extension.

Voice samples of 10 to 30 seconds work best; avoid background noise in them, or enable speaker denoising.

Features

  • Voice cloning: upload any audio sample to clone voices for any character you want.
  • Audio variants: different emotional versions of a character's voice (happy, sad, angry, and so on), with no limit on how many you add.
  • Emotion control: the AI automatically adds emotion values to dialogue, as the Zonos model supports it.
  • Multiple languages: English, Japanese, Chinese, French, German, and Korean.
  • Preloading: audio segments preload so playback does not pause for a long time mid generation.
  • Settings presets: save the model, language, speaking rate, voice quality score, and denoising choice under a name; presets import and export as JSON files, and changing a setting updates the active preset.

1Happiness5Surprise

4Fear8Neutral

Every dialogue segment the extension generates carries one of these values.

Using it

  • Auto generation: when enabled, TTS is generated for new messages automatically, as long as streaming is enabled.
  • Manual generation: click the wand icon in the menu, or the three dots on any message, then the wand.
  • Playback controls: toggle playback from inside SillyTavern.

Chat completions only, auto generation only while streaming is on, and a badly placed marker leaves a message silent.

The tests

node --test tests/index.test.mjs

15 tests, run with Node's built in test runner. index.js cannot load outside SillyTavern, so tests/harness.mjs loads it with the host modules stubbed and fetch recorded instead of sent. The tests cover marker parsing, narrator and character segment building, forced and unforced queue resets, the preload request body and its loading bookkeeping, preset seeding, emotion mapping, and the stream hook being removed instead of stacked on reinstall. Playback inside a real SillyTavern install is not covered.
